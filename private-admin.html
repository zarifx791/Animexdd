Step 1 — Add an Anime

প্রথমে Anime-এর নাম ও poster যোগ করে details page তৈরি করো। এরপর নিচের Episode Manager-এ সেই Anime select করে episode যোগ করবে।

Step 2 — Add Episodes

এখানে Anime series select করো, তারপর Episode title ও video URL দাও। আপাতত video file upload-এর সীমা ৫০ MB; বড় ভিডিওর জন্য file upload নয়, অনুমোদিত video host-এর official playable/embed URL ব্যবহার করো। Render-এর local storage-এ ভিডিও রাখবে না।

ভিডিও ফাইল অথবা URL—একটি বেছে নাও, দুটো একসাথে নয়। Host যদি official Embed URL দেয়, সেটি ব্যবহার করো। সাধারণ share link সবসময় player-এ চলে না; কিছু site external playback বন্ধ রাখে বা sign-in চায়। তাই আগে একটি ছোট test video দিয়ে পরীক্ষা করো। শুধু নিজের তৈরি বা বিতরণের অনুমতি আছে এমন ভিডিও publish করবে।
